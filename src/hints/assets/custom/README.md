# Пользовательские подсказки (custom hint assets)

Положите сюда JSON-файл с тем же именем, что и в `../default` (например
`permissions-editor.json`), — он **полностью заменит** встроенную подсказку.

Правило действует для **всех** ассетов: сначала ищется файл из `custom/`,
если он есть — используется он, иначе — встроенный из `default/`.

Формат файла:

```json
{
  "id": "permissions-editor",
  "title": "Права доступа пользователя",
  "blocks": [
    { "kind": "p", "text": "Абзац текста." },
    { "kind": "ul", "items": ["пункт списка", "ещё пункт"] },
    { "kind": "ol", "items": ["нумерованный пункт"] },
    { "kind": "code", "text": "моноширинная строка" }
  ]
}
```

Если файл не проходит проверку формата — подсказка останется встроенной
(невалидный кастомный ассет игнорируется).
