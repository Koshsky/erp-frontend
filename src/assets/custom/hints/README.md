# Пользовательские ассеты подсказок (custom/hints)

Каталоги ассетов зеркалят друг друга: `src/assets/default/<kind>/` — встроенные
файлы, `src/assets/custom/<kind>/` — пользовательские перекрытия (по умолчанию
пусто). Правило действует для **всех** видов (`hints`, `fonts`, …): сначала
ищется файл в `custom/<kind>/`, если он есть — используется он, иначе —
встроенный из `default/<kind>/`.

Положите сюда JSON с тем же именем, что в `../default/hints` (например
`permissions-editor.json`) — он **полностью заменит** встроенную подсказку.

Формат файла:

```json
{
  "id": "permissions-editor",
  "title": "Права доступа пользователя",
  "blocks": [
    { "kind": "p", "text": "Абзац текста." },
    { "kind": "ul", "items": ["пункт списка", "ещё пункт"] },
    { "kind": "ol", "items": ["нумерованный пункт"] },
    { "kind": "code", "text": "моноширинная строка" }
  ]
}
```

Невалидный файл игнорируется — подсказка останется встроенной.
