# Пользовательские ассеты подсказок (custom/hints)

Каталоги ассетов зеркалят друг друга: `src/assets/default/<kind>/` — встроенные
файлы, `src/assets/custom/<kind>/` — пользовательские перекрытия (по умолчанию
пусто). Правило действует для **всех** видов (`hints`, `icons`, …): сначала
ищется файл в `custom/<kind>/`, если он есть — используется он, иначе —
встроенный из `default/<kind>/`.

Подсказки разложены по языкам интерфейса: `default/hints/<locale>/<id>.md`
(сейчас `ru` и `en`). Положите сюда Markdown с тем же путём, что в
`../default/hints` (например `ru/permissions-editor.md` или
`en/permissions-editor.md`) — он **полностью заменит** встроенную подсказку для
этого языка. Файл без языковой папки игнорируется: имя ассета — это
`<locale>/<id>.md`.

Если перевода для текущего языка нет, панель показывает русский документ
(русский — язык продукта и резервный).

Формат файла — обычный Markdown:

```md
# Права доступа пользователя

Права пользователя: базовые — из пресета.

- Кнопки в строке — на какие записи действует право.
- «Сбросить индивидуальные» — вернуть всё к пресету.

Что означают кнопки:

```
Проект → Процесс → Задача → подзадачи
```
```

Правила:

- **id подсказки** — имя файла без расширения (`ru/permissions-editor.md` →
  `permissions-editor`).
- **заголовок** — первый заголовок `# ` в файле (если его нет — вместо
  заголовка показывается id).
- Остальной Markdown рендерится панелью подсказок: абзацы, списки, код,
  жирный/курсив, ссылки (`http/https/mailto`), GFM-таблицы.

Безопасность: сырой HTML в файле экранируется, ссылки на
`javascript:`/`data:` отбрасываются, картинки не рендерятся (показывается
alt-текст).

Невалидный файл (не текст или пустой) игнорируется — подсказка останется
встроенной.

> `README.md` в этом каталоге — документация, а не ассет: файлы, начинающиеся
> с `README`, никогда не интерпретируются как подсказки.
