# Users

The catalog of accounts: every user has a rights preset and, where needed, individual overrides.

- The login is auto-filled from the full name and checked for uniqueness.
- Individual permissions — on the user page, the "Edit permissions" button.
- Presets — in the "Rights presets" section; changes apply within the TTL (up to 30 seconds).
- The manager defines the reporting tree and "Own".
