# Пользователи

Каталог учётных записей: у каждого пользователя — пресет прав и, при необходимости, индивидуальные правки.

- Логин автозаполняется из ФИО и проверяется на уникальность.
- Индивидуальные права — на странице пользователя, кнопка «Изменить права».
- Пресеты — в разделе «Пресеты прав»; изменения применяются в пределах TTL (до 30 секунд).
- Руководитель определяет дерево подчинённости и «свои».
