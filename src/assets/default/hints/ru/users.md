# Пользователи

Каталог учётных записей: у каждого пользователя — роль и, при необходимости, индивидуальные правки.

- Логин автозаполняется из ФИО и проверяется на уникальность.
- Индивидуальные права — на странице пользователя, кнопка «Изменить права».
- Роли — в разделе «Роли»; изменения применяются в пределах TTL (до 30 секунд).
- Руководитель определяет дерево подчинённости и «свои».
