# Карточка пользователя

- Фамилия и Имя обязательны; логин заполнится из ФИО.
- Пресет — базис прав; его смена сразу перестраивает права.
- Индивидуальные права — на отдельной странице: «⚙ Изменить права» в шапке.
- Руководитель — непосредственный начальник в дереве структуры.
- Даты приёма/увольнения: уволенный не виден в планировании и табеле.
