# Структура компании

Иерархия организации: у каждого сотрудника есть руководитель, у руководителя — свой и т.д.

- Прямые подчинённые — те, у кого руководитель вы.
- Косвенные — подчинённые ваших подчинённых и ниже по дереву.
- «Свои» в табеле охватывают прямых и косвенных подчинённых.
- Смена руководителя сразу меняет видимость у обоих менеджеров.
