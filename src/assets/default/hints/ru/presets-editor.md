# Пресеты прав

Пресет — набор базовых прав. Слева выберите пресет, справа — его права по строкам (ресурс + действие).

- Кнопки в строке — на какие записи действует право; можно отметить несколько сразу.
- «⛔ нет доступа» — у строки нет правила.
- Изменения копятся внизу: «Сохранить» применяет их сразу, «Отменить» отбрасывает, «Сбросить всё к дефолтам» возвращает заводскую матрицу.
- Другие пользователи увидят изменения в пределах TTL кэша (до 30 секунд).

Что означают кнопки:

```
Проект → Процесс → Задача → подзадачи
```

Всё внутри записи — её потомки, всё снаружи (проект для задачи и т.п.) — её предки. У каждой записи есть владелец. Правило даёт доступ, если вы — владелец самой записи, её предка или записи внутри неё.

Кнопки:

1. «Свои» (self) — вы владелец записи. Пример: «задачи = Свои» — только ваши задачи.
2. «Родители» (up1) — вы владелец её непосредственного родителя. Пример: «задачи = Родители» — задачи ваших процессов.
3. «Предки» (up) — вы владелец любого предка. Пример: «задачи = Предки» — задачи ваших процессов и проектов.
4. «Сиблинги» (sib) — соседние записи под тем же родителем. Пример: «процессы = Сиблинги» — все процессы вашего проекта.
5. «Поддерево» (down) — внутри записи есть ваша запись. Пример: «проекты = Поддерево» — проекты, в которых есть ваши задачи.
6. «Все» (all) — весь справочник. «⛔» — запрет.

«Задачи = Предки» и «проекты = Поддерево» — разные правила: первое даёт задачи ваших проектов, второе — проекты с вашими задачами.

Сочетайте кнопки: «Свои» + «Сиблинги» = свои и соседние. «Все» и «⛔» — отдельно (сбрасывают остальные). Для вех и назначений нет «Свои»/«Сиблинги»/«Поддерево», у проекта нет «Родители»/«Предки»/«Сиблинги».

Пресеты слева: «+ Добавить» — создать; ✕ на кнопке — удалить (подтверждение вводом тэга); правый клик по кнопке — «Переименовать». У пресета три поля: имя (отображается в списке), тэг — код доступа (в синем бейджике) и описание; все три задаются при создании и редактируются при переименовании. Удаление снимает правила пресета и базовые права назначенных пользователей (пресет «admin» защищён).

Комментарии к задачам: права те же, что на задачу — видят их те, кому видна задача.
