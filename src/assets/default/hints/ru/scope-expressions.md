# Условия доступа

Выбирайте, какие объекты доступны сотруднику: **Все**, его собственные проекты или ресурсы, содержимое **его проектов** или **его процессов**. Проверяется именно указанный владелец; владельцы вложенных записей могут быть другими.

Несколько условий складываются: достаточно любого. «Все» заменяет остальные условия. «Нет доступа» убирает отдельное разрешение.

Для просмотра есть обязательное наследование: доступный проект открывает всё содержимое, процесс — своё содержимое, задача — подзадачи и назначения. Запрет ниже не отменяет доступ от родителя. При таком наследовании вместо запрета показано «Только через родителя»; для полностью открытого родителя управление просмотром ниже недоступно.

Для создания, изменения и удаления наследования нет. Право изменения приоритетов проектов настраивается отдельно. При назначении ресурс и процесс всегда должны иметь одного владельца.

Сиблинги и другие сложные условия больше не предлагаются в этой версии интерфейса. Уже сохранённые нестандартные правила не меняются автоматически: они показаны отдельно и действуют до явной замены.
