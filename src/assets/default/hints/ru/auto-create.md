# Триггер создания проекта

Триггер разворачивает проект по шаблону: проект → процессы (с владельцами) → задачи с ресурсами.

- Процесс без владельца создастся без него (не попадает в «свои»).
- Даты процессов и задач наследуют диапазон проекта; их можно править.
- Задачам назначаются выбранные ресурсы с количеством 1.
- Конфигурация применяется при следующем срабатывании триггера.
